OPULENCE — IVY PRESTO DISPLAY SETUP

1. Copy the CSS file into your Next.js project and import it where appropriate.
2. Put your licensed IvyPresto Display WOFF2 files here:
   public/fonts/IvyPrestoDisplay-Regular.woff2
   public/fonts/IvyPrestoDisplay-Semibold.woff2

Important:
The actual IvyPresto font files are NOT included because the font is commercially licensed.
Obtain the webfont files through your legitimate font license/provider.

If you only need the exact CSS setup, the included file is ready to use.
